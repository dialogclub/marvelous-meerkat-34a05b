# cinema.vision — «Одіссея»

Двуязычный промо-сайт встречи киноклуба cinema.vision, посвящённой фильму «Одіссея». Проект воспроизводит дизайн и содержание из переданного архива: украинская версия доступна на главной странице, английская — по адресу `/en`.

## Технологии

- Next.js 16 с App Router
- React 19 и TypeScript
- Адаптивный CSS без UI-фреймворков
- Netlify для сборки и публикации

## Локальный запуск

```bash
npm install
npm run dev
```

После запуска сайт открывается по адресу `http://localhost:3000`.

## Основные команды

- `npm run dev` — локальная разработка
- `npm run build` — production-сборка
- `npm run start` — запуск собранного приложения
- `npm run lint` — проверка ESLint

## Структура

- `app/CinemaVision.tsx` — общая разметка и двуязычный контент
- `app/globals.css` — визуальная система и адаптивные стили
- `app/page.tsx` — украинская версия
- `app/en/page.tsx` — английская версия
- `public/` — favicon и Open Graph-изображение
- `netlify.toml` — команда сборки для Netlify
